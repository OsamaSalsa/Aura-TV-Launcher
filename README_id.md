## ✨ Ringkasan

**Aura TV Launcher** bukan sekadar layar beranda biasa; ini adalah ekosistem hiburan lengkap yang dirancang dari awal untuk **Android TV dan Smart TV Box**. Dibangun 100% dengan **Kotlin** dan **Jetpack Compose**, Aura memadukan estetika "Glassmorphism" sinematik yang halus dengan berbagai fitur bawaan canggih seperti pemutar **IPTV / TV Langsung** bawaan, **Hub Cloud Gaming**, **Toko Aplikasi Aura Store**, serta **Mini Downloader** untuk memasang paket APK secara langsung.

Dirancang khusus untuk remote TV (navigasi D-Pad), setiap animasi, efek fokus, dan transisi disempurnakan untuk menghadirkan pengalaman 60 FPS yang mulus tanpa lag.

## 🎮 Panduan Pintasan Remote TV

Aura TV Launcher dirancang agar mudah dikendalikan dengan remote standar Android TV apa pun:

| Tombol Remote | Tempat Penggunaan | Tindakan yang Dilakukan |
| :--- | :--- | :--- |
| **Tombol OK / Pilih (Tekan Singkat)** | Aplikasi atau kartu apa pun | Membuka aplikasi, saluran, atau portal yang dipilih. |
| **Tombol OK / Pilih (Tekan Lama)** | Di atas ikon aplikasi | Membuka **Menu Opsi Cepat** (Sematkan/Lepas, Pindahkan, Sembunyikan, Kunci PIN, Info Aplikasi, Copot Pemasangan). |
| **Tombol Menu (☰ Tiga Garis)** | Di atas aplikasi atau Layar Beranda | Membuka menu konteks aplikasi yang sedang difokuskan atau panel pengaturan cepat. |
| **Tombol Suara / Google Assistant (🎤)** | Di mana saja dalam Launcher | Membuka **Pencarian Suara Universal** Aura untuk mencari aplikasi, saluran IPTV, atau menjalankan perintah suara. |
| **Tombol Arah (D-Pad)** | Di seluruh aplikasi | Navigasi mulus antar kategori, aplikasi, saluran, dan kontrol pemutar. |
| **Tombol Kembali (Back)** | Di dalam jendela / pemutar | Menutup menu yang terbuka, keluar dari pemutar layar penuh, atau kembali ke bagian atas layar beranda. |

> 💡 **Tips:** Anda juga dapat melihat panduan tombol lengkap ini langsung di dalam aplikasi melalui **Pengaturan > Panduan Remote**.

## 🛠️ Arsitektur & Teknologi

* **Bahasa Pemrograman:** 100% [Kotlin](https://kotlinlang.org/) dengan Coroutines dan StateFlow.
* **Antarmuka (UI):** 100% [Jetpack Compose](https://developer.android.com/jetpack/compose) + Material Design 3 adaptif untuk TV.
* **Arsitektur:** MVVM (Model-View-ViewModel) dengan pemisahan status yang bersih (`UiState`).
* **Pemutar Media:** [AndroidX Media3 / ExoPlayer](https://developer.android.com/guide/topics/media/media3) untuk stream HLS/M3U8.
* **Pemuatan Gambar:** [Coil](https://coil-kt.github.io/coil/) dengan cache disk dan memori yang dioptimalkan.
* **Jaringan & Cuaca:** OkHttp + Open-Meteo API untuk data cuaca akurat tanpa memerlukan kunci API.

## 📦 Cara Pemasangan

### Metode 1: Unduh APK Langsung (Disarankan)
1. Unduh file [`aura-tv-launcher.apk`](https://github.com/OsamaSalsa/Aura-TV-Launcher/releases/latest/download/aura-tv-launcher.apk) dari bagian Releases.
2. Kirim ke Android TV Anda melalui flashdisk USB, aplikasi *Send Files to TV*, atau *Downloader*.
3. Pasang APK dan berikan izin yang diminta.
4. Tekan tombol **Home** pada remote Anda dan pilih **Aura TV Launcher** sebagai aplikasi beranda bawaan (**"Selalu"**).

### Metode 2: Kompilasi dari Kode Sumber
```bash
git clone https://github.com/OsamaSalsa/Aura-TV-Launcher.git
cd Aura-TV-Launcher
./gradlew assembleDebug
```
File APK hasil kompilasi akan tersedia di `app/build/outputs/apk/debug/app-debug.apk`.
