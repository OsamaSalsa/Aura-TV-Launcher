## ✨ Przegląd

**Aura TV Launcher** to nie kolejny zwykły ekran główny — to kompletny ekosystem rozrywki zaprojektowany od podstaw dla **Android TV oraz przystawek Smart TV Box**. Stworzony w 100% w języku **Kotlin** z wykorzystaniem **Jetpack Compose**, Aura łączy płynną, kinową estetykę „Glassmorphism” z potężnymi wbudowanymi narzędziami, takimi jak natywny odtwarzacz **IPTV / Telewizji na żywo**, **Centrum Gier w Chmurze**, **Sklep z aplikacjami Aura Store** oraz **Mini Downloader** do bezpośredniej instalacji pakietów APK.

Zaprojektowany specjalnie pod obsługę pilotem telewizyjnym (nawigacja D-Pad), każdy element fokusu, animacja i przejście działa płynnie w 60 FPS bez przycięć.

## 🎮 Przewodnik po Przyciskach Pilota

Aura TV Launcher został zaprojektowany do intuicyjnej obsługi dowolnym standardowym pilotem Android TV:

| Przycisk na Pilocie | Gdzie Użyć | Wykonywana Akcja |
| :--- | :--- | :--- |
| **Przycisk OK / Wybierz (Krótkie naciśnięcie)** | Dowolna aplikacja lub karta | Otwiera wybraną aplikację, kanał lub portal. |
| **Przycisk OK / Wybierz (Długie przytrzymanie)** | Na ikonie aplikacji | Otwiera **Menu Szybkich Opcji** (Przypnij/Odepnij, Przenieś, Ukryj, Zablokuj PIN-em, Informacje o aplikacji, Odinstaluj). |
| **Przycisk Menu (☰ Trzy Linie)** | Na aplikacji lub Ekranie Głównym | Otwiera menu kontekstowe wybranej aplikacji lub szybki panel ustawień. |
| **Przycisk Głosu / Asystent Google (🎤)** | W dowolnym miejscu Launchera | Otwiera **Uniwersalne Wyszukiwanie Głosowe** Aura do szukania aplikacji, kanałów IPTV lub wydawania poleceń głosowych. |

## 🛠️ Architektura i Technologie

* **Język:** 100% [Kotlin](https://kotlinlang.org/) z Coroutines i StateFlow.
* **Interfejs (UI):** 100% [Jetpack Compose](https://developer.android.com/jetpack/compose) + Material Design 3 dla TV.
* **Architektura:** MVVM (Model-View-ViewModel) z czystym zarządzaniem stanem (`UiState`).
* **Odtwarzacz Multimediów:** [AndroidX Media3 / ExoPlayer](https://developer.android.com/guide/topics/media/media3) dla strumieni HLS/M3U8.
* **Ładowanie Obrazów:** [Coil](https://coil-kt.github.io/coil/) ze zoptymalizowaną pamięcią podręczną.
* **Sieć i Pogoda:** OkHttp + Open-Meteo API zapewniające dokładne dane pogodowe bez klucza API.

## 📦 Instalacja

### Metoda 1: Bezpośrednie Pobranie APK (Zalecane)
1. Pobierz plik [`aura-tv-launcher.apk`](https://github.com/OsamaSalsa/Aura-TV-Launcher/releases/latest/download/aura-tv-launcher.apk) z sekcji Releases.
2. Prześlij plik na swój telewizor Android TV za pomocą pamięci USB, aplikacji *Send Files to TV* lub *Downloader*.
3. Zainstaluj plik APK i przyznaj wymagane uprawnienia.
4. Naciśnij przycisk **Home** na pilocie i wybierz **Aura TV Launcher** jako domyślny ekran główny (**„Zawsze”**).

### Metoda 2: Kompilacja ze Źródeł
```bash
git clone https://github.com/OsamaSalsa/Aura-TV-Launcher.git
cd Aura-TV-Launcher
./gradlew assembleDebug
```
Skompilowany plik APK znajdziesz w `app/build/outputs/apk/debug/app-debug.apk`.
