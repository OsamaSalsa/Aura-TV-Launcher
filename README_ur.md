## ✨ عمومی جائزہ

**Aura TV Launcher** صرف ایک عام ہوم اسکرین نہیں ہے؛ بلکہ یہ ایک مکمل تفریحی ایکو سسٹم ہے جسے خاص طور پر **Android TV اور Smart TV Boxes** کے لیے ڈیزائن کیا گیا ہے۔ 100% **Kotlin** اور **Jetpack Compose** کے ساتھ تیار کردہ، Aura خوبصورت اور جدید "Glassmorphism" ڈیزائن کو طاقتور بلٹ ان ٹولز کے ساتھ یکجا کرتا ہے، جس میں بلٹ ان **IPTV / لائیو ٹی وی پلیئر**، **کلاؤڈ گیمنگ حب**، **Aura ایپ اسٹور**، اور براہ راست APK انسٹال کرنے کے لیے **منی ڈاؤن لوڈر (Mini Downloader)** شامل ہیں۔

ٹی وی ریموٹ کنٹرول (D-Pad نیویگیشن) کے لیے خاص طور پر تیار کیا گیا ہر اینیمیشن، فوکس ایفیکٹ اور ٹرانزیشن بغیر کسی رکاوٹ کے 60 FPS پر انتہائی ہموار تجربہ فراہم کرتا ہے۔

## 🛠️ آرکیٹیکچر اور ٹیکنالوجیز

* **پروگرامنگ زبان:** 100% [Kotlin](https://kotlinlang.org/) (Coroutines اور StateFlow کے ساتھ)۔
* **یوزر انٹرفیس (UI):** 100% [Jetpack Compose](https://developer.android.com/jetpack/compose) + ٹی وی کے لیے Material Design 3۔
* **آرکیٹیکچر:** صاف اسٹیٹ مینجمنٹ (`UiState`) کے ساتھ MVVM (Model-View-ViewModel)۔
* **میڈیا پلیئر:** HLS/M3U8 اسٹریمز کے لیے [AndroidX Media3 / ExoPlayer](https://developer.android.com/guide/topics/media/media3)۔
* **تصاویر کی لوڈنگ:** تیز رفتار ڈسک اور میموری کیشے کے ساتھ [Coil](https://coil-kt.github.io/coil/)۔
* **نیٹ ورک اور موسم:** بغیر API کلید کے درست موسمی معلومات کے لیے OkHttp + Open-Meteo API۔

## 📦 انسٹالیشن کا طریقہ

### طریقہ 1: براہ راست APK ڈاؤن لوڈ کریں (تجویز کردہ)
1. Releases سیکشن سے [`aura-tv-launcher.apk`](https://github.com/OsamaSalsa/Aura-TV-Launcher/releases/latest/download/aura-tv-launcher.apk) فائل ڈاؤن لوڈ کریں۔
2. اسے USB فلیش ڈرائیو، *Send Files to TV* ایپ یا *Downloader* کے ذریعے اپنے Android TV میں منتقل کریں۔
3. APK انسٹال کریں اور مطلوبہ اجازتیں (Permissions) دیں۔
4. اپنے ریموٹ پر **Home** بٹن دبائیں اور **Aura TV Launcher** کو بطور ڈیفالٹ لانچر (**"ہمیشہ / Always"**) منتخب کریں۔

### طریقہ 2: سورس کوڈ سے بلڈ (Build) کریں
```bash
git clone https://github.com/OsamaSalsa/Aura-TV-Launcher.git
cd Aura-TV-Launcher
./gradlew assembleDebug
```
تیار شدہ APK فائل `app/build/outputs/apk/debug/app-debug.apk` میں دستیاب ہوگی۔
