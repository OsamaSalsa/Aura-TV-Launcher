## ✨ Visão Geral

O **Aura TV Launcher** não é apenas mais uma tela inicial; é um ecossistema completo de entretenimento criado do zero para **Android TV e Smart Boxes**. Construído 100% com **Kotlin** e **Jetpack Compose**, o Aura combina uma estética fluida e cinematográfica em estilo "Glassmorphism" com ferramentas poderosas integradas, como um reprodutor **IPTV / TV ao Vivo** nativo, um **Hub de Jogos na Nuvem**, a **Loja de Aplicativos Aura** e um **Mini Downloader** para instalação direta de pacotes APK.

Projetado especificamente para controles remotos de TV (navegação D-Pad), cada animação, estado de foco e transição é ajustado para oferecer uma experiência suave a 60 FPS sem travamentos.

## 🎮 Guia de Atalhos do Controle Remoto

O Aura TV Launcher foi projetado para ser controlado sem esforço com qualquer controle remoto padrão de Android TV:

| Botão no Controle | Onde Usar | Ação Executada |
| :--- | :--- | :--- |
| **Botão OK / Selecionar (Toque Curto)** | Qualquer aplicativo ou cartão | Abre o aplicativo, canal ou portal selecionado. |
| **Botão OK / Selecionar (Pressão Longa)** | Sobre um aplicativo | Abre o **Menu de Opções Rápidas** (Fixar/Desafixar, Mover, Ocultar, Bloquear com PIN, Informações do App, Desinstalar). |
| **Botão Menu (☰ Três Linhas)** | Sobre um aplicativo ou na Tela Inicial | Abre o menu de contexto do aplicativo focado ou o painel rápido de configurações. |
| **Botão de Voz / Google Assistant (🎤)** | Em qualquer lugar do Launcher | Abre a **Busca Universal por Voz** do Aura para pesquisar aplicativos, canais IPTV ou executar comandos de voz. |
| **Botões Direcionais (D-Pad)** | Em todo o aplicativo | Navega suavemente entre categorias, aplicativos, canais e controles de reprodução. |
| **Botão Voltar (Back)** | Dentro de janelas/players | Fecha menus abertos, sai do player em tela cheia ou retorna ao topo da tela inicial. |

> 💡 **Dica:** Você também pode consultar este guia completo de botões diretamente dentro do aplicativo em **Configurações > Guia do Controle Remoto**.

## 🛠️ Arquitetura e Tecnologias

* **Linguagem:** 100% [Kotlin](https://kotlinlang.org/) com Coroutines e StateFlow.
* **Interface (UI):** 100% [Jetpack Compose](https://developer.android.com/jetpack/compose) + Material Design 3 adaptativo para TV.
* **Arquitetura:** MVVM (Model-View-ViewModel) com separação limpa de estado (`UiState`).
* **Reprodução de Mídia:** [AndroidX Media3 / ExoPlayer](https://developer.android.com/guide/topics/media/media3) para streams HLS/M3U8.
* **Carregamento de Imagens:** [Coil](https://coil-kt.github.io/coil/) com cache em disco e memória otimizado.
* **Rede e Clima:** OkHttp + API Open-Meteo para dados meteorológicos precisos sem necessidade de chave de API.

## 📦 Instalação

### Método 1: Download Direto do APK (Recomendado)
1. Baixe o arquivo [`aura-tv-launcher.apk`](https://github.com/OsamaSalsa/Aura-TV-Launcher/releases/latest/download/aura-tv-launcher.apk) na seção Releases.
2. Transfira para sua Android TV via pendrive USB, aplicativo *Send Files to TV* ou *Downloader*.
3. Instale o APK e conceda as permissões solicitadas.
4. Pressione o botão **Home** no seu controle remoto e selecione **Aura TV Launcher** como seu aplicativo inicial padrão (**"Sempre"**).

### Método 2: Compilar a partir do Código-Fonte
```bash
git clone https://github.com/OsamaSalsa/Aura-TV-Launcher.git
cd Aura-TV-Launcher
./gradlew assembleDebug
```
O arquivo APK compilado estará disponível em `app/build/outputs/apk/debug/app-debug.apk`.
